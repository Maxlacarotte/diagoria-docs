Kit de marque DIAGORIA

Tous les assets SVG du logo officiel (#34 Arcs rayonnants), rangés par usage et par fond. Pour chaque variante : apercu rendu, nom du fichier, snippet inline copiable et bouton de téléchargement.

Quelle variante utiliser ?
  • En-tête site / app fond clair → logo-horizontal.svg
  • En-tête document officiel / mail → logo-signature.svg
  • Dark mode / interface sombre → logo-horizontal-nuit.svg
  • App icon / avatar carré → logo-empile.svg ou favicon.svg
  • Favicon navigateur → favicon.svg
  • Impression monochrome / fax → logo-picto-mono.svg + texte encre
  • Fond coloré dégradé → logo-horizontal-blanc.svg
  • Variante créative (wordmark fusionné) → logo-integre.svg
