Note technique — polices dans les SVG

Les fichiers SVG embarquent font-family="Fredoka, sans-serif". La police s'affiche correctement dans les navigateurs car Google Fonts est chargée dans les pages HTML. Dans les contextes sans réseau (visualiseur SVG natif, export PDF), le fallback sans-serif est visuellement acceptable — la forme du wordmark ne se casse pas.

7. Do / Don't

A faire

  • Toujours respecter la zone de protection
  • Utiliser la version nuit sur fond sombre
  • Utiliser le monochrome pour l'impression noir et blanc
  • Conserver les proportions d'origine (SVG vectoriel)
  • Préférer logo-signature.svg pour les en-têtes documents
  • Charger Fredoka via Google Fonts dans les pages HTML
  • Utiliser favicon.svg en dessous de 48 px

A ne pas faire

  • Déformer, étirer, ou mettre à l'échelle non uniformément
  • Changer les couleurs du dégradé ou du point ambre
  • Ajouter des ombres portées, des reflets, des embossages
  • Placer le logo sur un fond qui ne respecte pas le contraste AA
  • Utiliser la version couleur sur fond coloré foncé (utiliser la version nuit)
  • Combiner le logo avec un autre logo sans zone de protection intermédiaire
  • Réécrire le wordmark dans une autre police

8. Le sens de la marque

~

Signal

Les deux arcs rayonnants évoquent l'onde sonore, l'émission, la voix qui porte. La transcription commence par une intention : parler.

O

Sérénité

La forme est calme, symétrique, ouverte vers le haut. Rien d'agressif. L'outil s'efface pour que le praticien reste entier dans sa consultation.

*

Point pivot ambre

Le foyer d'où part tout le signal. Le praticien, la voix, l'instant présent. L'ambre chaud dans le froid teal-bleu : l'humain dans la technologie.

EU

Souveraineté

Teal + bleu = palette technique européenne. Ni les rouges agressifs du marketing US, ni les verts trop "nature". Un outil médical, sérieux, d'ici.

Aa

Fredoka

La typographie ronde et accessible dit : "pas d'inquiétude, je suis facile à utiliser." Contraste avec la rigueur du domaine médical — c'est voulu.

dia

Etymologie

Dia (dialogue, diagnostic, à travers) + -oria (lieu, espace). DIAGORIA est l'espace où le diagnostic prend forme à travers le dialogue.
